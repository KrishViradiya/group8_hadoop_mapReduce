Module Title: MapReduce System - Output Management and Data Serialization

High-Level Descriptive Summary:
The MapReduce System - Output Management and Data Serialization module is pivotal in managing the final stages of data processing in a MapReduce job. It encompasses components responsible for defining, formatting, and serializing output data, ensuring it adheres to specified structures before being written to the Hadoop FileSystem. This module includes classes for various output formats (Text, SequenceFile binary, and custom formats), output committers for task output management, and collectors for aggregating key-value pairs. It also incorporates utility classes for handling file operations and filtering, ensuring data integrity through checksum verification during input and output processes. The system's design facilitates scalability by enabling different output formats and structures, catering to diverse data serialization needs. Fault-tolerance is maintained through the committer's role in managing job output stages, ensuring data consistency even in the event of task failures.

The component layer consists of the following key elements:
* FileOutputCommitter: Manages the commit, setup, cleanup, and discard processes of task outputs for a Map-Reduce job.
* FileOutputFormat: Provides a base implementation for output formats writing to Hadoop's FileSystem.
* IFileInputStream: Offers a checksum-verified input stream for reading data from InputFiles created by IFileOutputStream.
* IFileOutputStream: Provides a checksum output stream for writing data to files in Apache Hadoop MapReduce.
* MapFileOutputFormat: Specialized output format for MapFiles, a compressed, column-oriented storage file format used in Hadoop.
* MapOutputCollector: Central component for collecting and aggregating intermediate key-value pairs generated by Mapper tasks.
* MapReduceBase: Base class for implementing Mapper and Reducer components, providing common functionality.
* OutputCollector: Collects and aggregates key-value pairs generated by Mapper and Reducer tasks.
* OutputCommitter: Manages the commit, setup, cleanup, and discard processes of task outputs for a Map-Reduce job.
* OutputFormat: Defines the specification for the output of a MapReduce job, including formatting and serialization.
* OutputLogFilter: Filters log files from a given directory in Apache Hadoop MapReduce.
* RecordWriter: Writes the output `<key, value>` pairs to an output file, adhering to the specified OutputFormat.
* SequenceFileAsBinaryOutputFormat: An OutputFormat for writing keys and values to SequenceFiles in binary format.
* SequenceFileOutputFormat: An OutputFormat for writing data into SequenceFile format in Apache Hadoop MapReduce jobs.
* TextOutputFormat: An OutputFormat for writing plain text files in Apache Hadoop MapReduce jobs.
* Utils: Provides utility methods for file filtering, specifically handling output and log files in the context of MapReduce jobs.
