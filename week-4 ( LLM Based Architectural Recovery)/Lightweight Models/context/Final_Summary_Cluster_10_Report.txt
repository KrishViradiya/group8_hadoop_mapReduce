Module Title: MapReduce System - Data Input and Splitting Layer

High-Level Descriptive Summary:
The Data Input and Splitting Layer of the MapReduce System is pivotal for preparing data for processing by the MapReduce framework. This layer encompasses components responsible for reading data from diverse databases and splitting it into manageable chunks or partitions. The system supports various data types, including integers, floating-point numbers, dates, and text, ensuring flexibility in handling different data formats. The DataDrivenDBInputFormat and its associated record readers (such as DataDrivenDBRecordReader, MySQLDBRecordReader, OracleDataDrivenDBRecordReader) facilitate data extraction from relational databases like MySQL and Oracle. Meanwhile, specialized splitters (IntegerSplitter, FloatSplitter, DateSplitter, TextSplitter) divide the data based on specific criteria, preparing it for parallel processing by MapReduce tasks. This layer's design ensures that data is efficiently ingested and segmented, setting the stage for subsequent Map and Reduce phases in the MapReduce job lifecycle.

The component layer consists of the following key elements:
* DataDrivenDBInputFormat: Manages database input formats for data-driven records.
* FloatSplitter: Splits data based on floating-point values.
* IntegerSplitter: Splits integer data into smaller partitions.
* DateSplitter: Splits input data using date fields.
* DataDrivenDBRecordReader: Reads data from databases, adaptable to different database systems.
* DBInputFormat: Defines the input format for database records in MapReduce.
* DBConfiguration: Holds configuration settings for database connections.
* MySQLDBRecordReader: Specialized reader for MySQL databases.
* DBWritable: Interface for defining how database records are written and read by MapReduce.
* TextSplitter: Splits text data into key-value pairs for MapReduce processing.
* MySQLDataDrivenDBRecordReader: Tailored reader for MySQL databases using data-driven approaches.
* DBRecordReader: General-purpose record reader for database inputs.
* BooleanSplitter: Splits data based on boolean conditions.
* BigDecimalSplitter: Handles splitting of BigDecimal data types.
* OracleDataDrivenDBRecordReader: Reader for Oracle databases utilizing data-driven methods.
* OracleDBRecordReader: Specialized reader for Oracle databases.
* DBSplitter: General class for splitting database records.
* OracleDataDrivenDBInputFormat: Input format specific to Oracle databases using data-driven techniques.
* DBOutputFormat: Defines the output format for database records post-MapReduce processing.

Concluding Paragraph:
This layer's components are engineered with scalability in mind, allowing the system to handle large datasets by efficiently distributing them across the cluster.
