Key Functionality: A class for writing a manifest of output files.
Core Logic: The class writes a manifest of output files by creating a thread pool to write the manifest entries to a blocking queue. The manifest entries are then written to a SequenceFile.Writer in a separate thread. The class also handles exceptions and ensures that the manifest is properly closed.
Inputs/Outputs: The class takes a Configuration object, a manifest path, and a list of manifest entries as input. It writes the manifest entries to a SequenceFile.Writer and creates a manifest file.
Dependencies: The class depends on the Configuration, Path, NullWritable, SequenceFile, and HadoopExecutors classes.
