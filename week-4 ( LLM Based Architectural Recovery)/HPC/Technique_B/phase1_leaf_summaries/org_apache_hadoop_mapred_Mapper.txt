Key Functionality:
- Maps input key/value pairs to a set of intermediate key/value pairs.

Core Logic:
- The Hadoop Map-Reduce framework spawns one map task for each InputSplit generated by the InputFormat for the job.
- Mapper implementations can access the JobConf for the job via the JobConfigurable.configure(JobConf) and initialize themselves.
- The framework then calls map(Object, Object, OutputCollector, Reporter) for each key/value pair in the InputSplit for the job.

Inputs/Outputs:
- Input key/value pairs
- Intermediate key/value pairs
