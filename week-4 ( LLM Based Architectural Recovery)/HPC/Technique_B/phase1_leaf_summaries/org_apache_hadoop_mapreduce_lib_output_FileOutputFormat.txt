Key Functionality: Base class for OutputFormats that read from FileSystems.
Core Logic: The core logic of this class is to handle the creation of the RecordWriter, which is responsible for writing the output data. The getRecordWriter method creates the RecordWriter by checking if a compression codec is specified, and if so, it creates a compression writer. Otherwise, it creates a regular writer. The checkOutputSpecs method checks if the output directory already exists and throws an exception if it does. The getOutputCommitter method returns the output committer, which is responsible for committing or aborting the task.
Inputs/Outputs: The class takes in a Configuration object and a Path object as inputs, and it returns a RecordWriter object as an output.
Dependencies: The class depends on the Configuration, FileSystem, Path, CompressionCodec, OutputCommitter, RecordWriter, JobContext, TaskAttemptContext, TaskID, TaskInputOutputContext, TokenCache, FileAlreadyExistsException, InvalidJobConfException, IOException, and LoggerFactory classes.
