Key Functionality: Writes the output <key, value> pairs to an output file.
Core Logic: The RecordWriter class is an abstract class that must be implemented by any class that writes the output <key, value> pairs to an output file.
Inputs/Outputs: The write() method takes in a key and a value and writes them to the output file. The close() method is used to close the RecordWriter to future operations.
Dependencies: The RecordWriter class depends on the FileSystem class for writing the output file.
