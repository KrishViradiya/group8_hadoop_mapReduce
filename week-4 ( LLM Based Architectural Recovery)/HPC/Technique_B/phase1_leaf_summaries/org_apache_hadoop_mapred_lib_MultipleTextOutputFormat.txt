Key Functionality: Write output data to different output files in Text output format.
Core Logic: Extends the MultipleOutputFormat class and overrides the getBaseRecordWriter method to use the TextOutputFormat for writing the output data.
Inputs/Outputs: FileSystem fs, JobConf job, String name, Progressable arg3
