Module Title: "MapReduce System: Checkpointing and Output Commitment"

High-Level Descriptive Summary:
The MapReduce System is responsible for processing large-scale data sets using a distributed computing framework. It consists of a master node and multiple slave nodes, each running a MapReduce task. The master node coordinates the tasks and manages the distribution of data across the slave nodes.

The Checkpointing and Output Commitment module is responsible for managing the checkpointing and commitment of task output for each MapReduce task. It ensures that the output of each task is durable and can be recovered in case of task failure.

The CheckpointService class provides a simple API to store and retrieve the state of a task. Checkpoints are atomic, single-writer, write-once, multiple-readers, ready-many type of objects. This is provided by releasing the CheckpointID for a checkpoint only upon commit of the checkpoint, and by preventing a checkpoint to be re-opened for writes.

The OutputCommitter class coordinates the commit of task output for a Map-Reduce job. It is responsible for setup and cleanup of the job, setup of task temporary output, checking whether a task needs a commit, committing task output, and discarding task commit.

The FileOutputCommitter class is an implementation of the OutputCommitter class that commits files specified in the job output directory. It renames the files from the temporary directory to the job output directory.

The CheckpointService and OutputCommitter classes work together to ensure that the output of each task is durable and can be recovered in case of task failure. The CheckpointService provides a channel to write to a checkpoint and a channel to read from a checkpoint, while the OutputCommitter coordinates the commit of task output for a Map-Reduce job.
